# CD Shelf for Music Assistant

Browse your albums as a shelf of CD spines, open a cover and play it on an Onkyo, Denon, Sonos or another player configured in Music Assistant.

Configure the Music Assistant address and access token once in this app's Configuration tab. Open CD Shelf from the Home Assistant sidebar on any signed-in screen; no browser token setup is needed.

First experimental Home Assistant release, targeting Music Assistant **2.10.9**. The frontend and backend are tested locally; installation and Ingress operation on a real Home Assistant OS system still need verification. See the Documentation tab for setup.

Based on CD Shelf by ChrisHoppyBot, with LMS packaging/UI by Joe Leech. The original code's attribution is retained; no new licence is assigned by this adaptation.

Use **Full screen** at the top for a clean CD Shelf view, or **Open on its own** to open the current Ingress session in a separate tab without Home Assistant navigation. Browser full-screen support and session lifetime still apply.
