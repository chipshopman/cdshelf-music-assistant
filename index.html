    CD Shelf connection

    Your albums stay on your NAS. Connect to the Music Assistant server that already plays them.

    The connection is configured centrally in Home Assistant. Everyone can open the collection without entering a Music Assistant token.

    Use Music Assistant’s direct address, usually port 8095—not the Home Assistant sidebar URL.
    Create a token in Music Assistant’s user/profile settings. This is a Music Assistant token, not a Home Assistant token. Do not share it in GitHub or chat. Saves the token in this browser on this device. Uncheck for a shared device; the token then stays in memory only.

    Ready to connect.

    Your players

    Choose the room you want to play in, then browse your collection above. Playback starts only when you press Play album.

    Having trouble connecting?
    • Open the Music Assistant address in another browser tab first to check it is reachable.
    • Use a Music Assistant user token with permission to read players.
    • Allow local-network access if your browser asks. Your screen and server must be able to reach one another.
    • An HTTPS page cannot connect to an insecure HTTP server. Run CD Shelf over local HTTP, or use HTTPS for both.
