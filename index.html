Having trouble connecting?
  • Open the Music Assistant address in another browser tab first to check it is reachable.
  • Use a Music Assistant user token with permission to read players.
  • Allow local-network access if your browser asks. Your screen and server must be able to reach one another.
  • An HTTPS page cannot connect to an insecure HTTP server. Run CD Shelf over local HTTP, or use HTTPS for both.
